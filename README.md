# Marlo Reyes Portfolio

A portfolio site for a pretend landscape photographer. Marlo, the photos and the places are made up. I built it to practice making a first screen that feels alive.

Live version: https://areebamalik0.github.io/marlo-portfolio/

The top of the page is a sunset scene made only with CSS: a glowing sun, three layers of mountains and a title that builds itself letter by letter. The mountains move slightly with your mouse, and small glowing dust drifts upward. When you scroll down, the sun sinks, the sky turns purple and stars come out.

The "photos" in the work section are gradients, not real images. Below that there are numbers that count up, an accordion for how a commission works, and a contact form that checks your input but doesn't send anything.

Built with plain HTML, CSS and JavaScript. No frameworks. To run it, download the files and open index.html in your browser.
